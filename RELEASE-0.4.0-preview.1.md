Reusable sequential workflows and one-shot agents with the native Codex terminal and fresh 16K sessions.

- Guided workflow and agent editors, saved profiles, duplication, JSON loading, and per-role models.
- Writing studio and customizable code builder presets alongside the original coding engine.
- One-shot work on empty projects or separate copies of existing codebases.
- Validated routes, revision handoffs, frozen templates, required outputs, and bounded run budgets.
- Continue, stop, native steering, and reopen at any selected role.
- Protected-file restoration with archived attempted edits; port-release waiting; cleanup after storage errors.
- Bundled provider proxy and launcher retained.

Windows preview ready for user trials. Controller/menu tests and real Codex integration with deterministic provider responses pass. Live-model task quality still needs testing. No visual workflow canvas or parallel scheduling is included.

Extract the ZIP and open Start Conductor.cmd. Configure provider settings (8), then W for workflows or O for one-shot. See WORKFLOWS.md.
