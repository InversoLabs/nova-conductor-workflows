01 / DESIGN THE WAY WORK HAPPENSSMALL ROLES. CONNECTED WORK.

A workflow that
fits the job.

Start with the code builder, create your own flow, or send a single agent into an existing codebase with focused instructions.

↗

Connect the pieces.

Drop roles into the visual builder and wire their outcomes. Save the workflow as a reusable template.

▦

Give agents a purpose.

Set responsibilities, input files, expected outputs, and access. A producer, writer, editor—or your own combination.

⌘

Keep the Codex experience.

Follow native tool activity in a side-by-side Codex window. Each role change starts a fresh session; files carry the handoff.

⚙

Let robots do the routine.

Use script nodes for checks, processing, uploads, or deployment. Route failures explicitly and keep retries bounded.

◷

Put a flow on a schedule.

Run editions at saved daily times. The Windows host must be available and signed in to execute scheduled work.

◎

Choose your model provider.

Connect Nova Bridge, Ollama, LM Studio, or a compatible endpoint through the bundled proxy. Model tool reliability varies.

02 / BUILT WITH CONDUCTOR

A real newsroom.
A visible experiment.

IN / SIGNAL collects primary sources, drafts a briefing, checks it, reviews the evidence, then creates an abstract illustration and publishes over SSH.

Publication needs approval. Failed checks hold the edition. AI review can miss errors, so stories include source links and visible corrections.
